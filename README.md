# .github

Account-wide default community health files for repositories under this
account. GitHub falls back to the files in this repository's `.github/`
directory for any repository that doesn't provide its own copy:
`CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`,
`pull_request_template.md`, and the issue templates.

## What's here

- `.github/CONTRIBUTING.md` — default contribution workflow and commit
  conventions.
- `.github/SECURITY.md` — default vulnerability reporting policy.
- `.github/CODE_OF_CONDUCT.md` — Contributor Covenant 2.1.
- `.github/pull_request_template.md` — default pull request body sections.
- `.github/ISSUE_TEMPLATE/` — default bug report and feature request forms.

A repository that needs different rules (its own `CONTRIBUTING.md`, a
stricter `SECURITY.md`, etc.) can add its own copy of any of these files,
which GitHub will use in place of the default.
