## 🏴‍☠️ QuestFree — Flagship Project

**Repurpose your discontinued Meta Quest 1 on Linux.**  
No Meta servers. No Horizon app. No account required for device operation.

- Full BLE companion protocol implementation (STELLA/ALOHA)
- Local NUX spoof server — setup completes with WAN completely offline  
- Developer mode + ADB without Meta's infrastructure  
- Stage 1 ADB strip — removes telemetry/social layer (reversible, no root)  
- Based on full firmware RE of the final Quest 1 build (Jul 31 2024)

**→ [github.com/frankstupak/questfree](https://github.com/frankstupak/questfree)**

## Philosophy

Old hardware is not dead hardware. The Quest 1 was discontinued. The Nest thermostat lost its cloud. Roborock got locked down. Each one is a capable Linux-adjacent device being artificially retired. The work here is about finding the seam between "end of support" and "end of life" — and proving they're not the same thing.

> *"Unshackling forgotten hardware."*
